# HAL経営相談室 ホームページ

AI導入支援と補助金活用に強みを持つ中小企業診断士事務所のサイト（1ページ構成）。

- `index.html` … サイト本体（HTML・CSS・JavaScriptを1ファイルに収録）
- `favicon.svg` … ブラウザのタブに出るアイコン
- `IMAGE` / `PORTRAIT` の画像枠と連絡先（`info@example.com`）は差し替え前提です
- `business/contact-form.md` … 無料相談フォーム（Googleフォーム）の設計案
- `designs/` … 採用しなかったデザイン案の控え（`a-noir.html` 濃紺×金、`c-emerald.html` 深緑×シャンパン、`d-midnight.html` 黒×青紫の光）。内容は更新していません
- `brand/` … ブランド素材
  - `logo/` … ロゴ（C案）。`hal-mark.svg` 標準、`hal-mark-white.svg` 濃い背景用、`hal-mark-navy-bg.svg` 紺地付き
  - `business-card.html` / `.pdf` … 名刺（91×55mm、表裏）。メールとURL、QRコードは仮
  - `logo-options.html` … ロゴ案の比較用
  - `image-list.md` … 画像生成AIで用意する画像の一覧と指示文
  - `ogp.png` … SNSで共有されたときの画像（公開時にドメインと合わせて設定）
- `apple-touch-icon.png` … スマホのホーム画面に追加したときのアイコン
- `business/` … 事業運営の資料（たたき台）
  - `pricing.md` … 支援メニューと料金表
  - `service-manual.md` … サービスの進め方マニュアル
  - `contact-and-address.md` … 電話番号と住所の運用案
