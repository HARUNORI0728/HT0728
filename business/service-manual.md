## 0. 全サービス共通の流れ

```
問い合わせ → 初回無料相談 → 提案・見積 → 契約 → 実施 → 報告 → 請求 → その後のフォロー
```

| 段階 | やること | 使うもの | 目安 |
|---|---|---|---|
| 問い合わせ | **24時間以内（遅くとも翌日夜まで）に返信**。日程候補を出す | 問い合わせフォーム、メールの返信テンプレート、予約ページ | 当日〜翌日 |
| 初回相談の準備 | 相手の会社のホームページを読み、事前アンケートを送る | ヒアリングシート | 相談の2〜3日前 |
| 初回相談 | 60分。困りごとの整理と、進め方の案を伝える | 下の「1.」の台本 | 60分 |
| 提案・見積 | **相談から3営業日以内**に、提案書（1〜2枚）と見積書を送る | 提案書・見積書のひな形 | 3日以内 |
| 契約 | 業務委託契約書（または注文書と請書）、必要なら秘密保持契約 | 契約書のひな形 | — |
| 実施 | 面談ごとに議事メモを残し、**次にやることと担当者**を明確にする | 議事メモのひな形 | — |
| 報告 | 成果物を渡し、できたこと・残った課題・次の一手を伝える | 報告書のひな形 | — |
| 請求 | 請求書を送る（インボイス登録をしたら登録番号を記載） | 会計ソフト | 完了後すぐ |
| フォロー | **1か月後と3か月後に「その後いかがですか」と連絡**。次の依頼や紹介につながる | カレンダーのリマインダー | — |

**運用のポイント**

- 予約は **Google Workspace のカレンダー「予約スケジュール」** を使うと、空き時間だけを相手に見せて予約してもらえます。平日昼の電話のやり取りが不要になり、副業と相性がよいです。
- お客様ごとに **Googleドライブにフォルダ**を作り、そこにすべての資料を集めます。勤務先のPCやアカウントは**絶対に使わない**。
- ひな形（ヒアリングシート、提案書、見積書、契約書、議事メモ、報告書）は、最初の1件目のときに作り、2件目から使い回します。必要になったら、このスレッドで一緒に作れます。

## 1. 初回無料相談

**目的**：困りごとを整理し、「この人に頼めば前に進めそう」と感じてもらうこと。**売り込む場ではありません**（サイトでも「無理な勧誘はしない」と約束しています）。

### 事前準備

- 事前アンケート（5問程度）を送る：
  1. 会社の概要（業種、従業員数）
  2. 今いちばん困っていること
  3. AIや補助金について、すでに試したこと・調べたこと
  4. 相談後にどうなっていたら嬉しいか
  5. 予算や時期の目安（分かる範囲で）
- 相手の会社のホームページと、業界でよくある課題を確認しておく。

### 60分の台本

| 時間 | 内容 | ポイント |
|---|---|---|
| 0〜5分 | あいさつ、自己紹介、今日の進め方 | 「今日はご状況を伺って、進め方の案をお伝えします。ご契約が前提ではありません」と最初に言う |
| 5〜30分 | 話を聞く | 業務の流れ、誰が何に時間を使っているか、困っていることを具体的に。**数字（時間・件数・金額）を聞く** |
| 30〜45分 | その場での整理と、すぐ役立つ助言 | ホワイトボード（またはオンラインの画面共有）で課題を3つ程度に整理する。**無料でも、1つは持ち帰れるヒントを渡す** |
| 45〜55分 | 進め方の案 | 「自社でできること」と「支援があると早いこと」を分けて伝える。支援する場合のメニューと料金の目安を伝える |
| 55〜60分 | 次の約束 | 「3営業日以内に提案書と見積をお送りします」。または「今日の内容で進められそうなら、それで十分です」 |

### 相談のあと

- 当日中にお礼のメールと、**相談内容の要点メモ**を送る（これだけで信頼度が大きく上がります）。
- 依頼につながらなくても、**1〜3か月後に一度だけ**近況を伺う。それ以上は追わない。

### 断る・他を紹介する判断

- 税務・労務・法律の手続きが中心 → 税理士・社労士・行政書士・弁護士を紹介
- 資金繰りが厳しく、すぐに専門的な再建支援が必要 → 東京都の中小企業活性化協議会、取引銀行、よろず支援拠点などの公的窓口を案内
- 大規模なシステム開発が必要 → 開発会社を紹介（自分で請け負わない）

## 2. スポット相談

**目的**：1つのテーマについて、1回で答えや方向性を出す。

1. 予約時に**テーマを一文で書いてもらう**（例：「ChatGPTを社員に使わせたいが、何に気をつければよいか」）。
2. 事前に資料があれば送ってもらう。
3. 当日：**最初の5分で、ゴール（今日持ち帰りたいもの）を確認**してから話す。
4. 終了後24時間以内に、要点と「次にやること」をメールで送る。
5. 料金は**事前振込**、またはカード決済（Square、Stripe などの決済リンク）にすると、未払いの心配がありません。

**ポイント**：スポット相談を2〜3回くり返すお客様には、顧問契約を案内すると、お互いに割安・手間が少なくなります。

## 3. 講習会・研修

### 3-1. 公的機関・団体主催のセミナー講師

**実績と知名度づくりの近道**です。商工会議所、商工会、区の産業振興の部署、金融機関、業界団体などが主催します。

- **入り口**：東京都中小企業診断士協会の研究会・支部の活動に参加して、講師の募集情報を得る。台東区の産業振興の部署、東京商工会議所の台東支部に、テーマ案を持ってあいさつに行く。
- **企画書（A4で1枚）**に書くこと：タイトル、対象者、受講後にできるようになること、2時間の構成、講師プロフィール（勤務先名は出さない）。
- **謝金は主催者の規程**で決まることが多いので、交渉より「次につながるか」を重視する。
- **受講者アンケートに「個別相談を希望する」の欄を入れてもらえるか**、主催者に相談する（集客につながります）。

### 3-2. 企業の社内研修

| 段階 | やること |
|---|---|
| 事前打ち合わせ（60分） | 受講者の人数・職種・ITへの慣れ、研修後にどうなってほしいか、使っているAIサービス、**会社の情報管理ルール**を確認 |
| 事前アンケート | 受講者に「AIを使ったことがあるか」「業務で困っていること」を聞く |
| 資料づくり | **その会社の実際の業務を例題にする**（汎用的な内容だけにしない）。助成金を使う場合も、事業と結びついた内容にする必要がある |
| 当日（半日の例） | ① AIで何ができる・できない（30分）② 安全な使い方とルール（30分）③ 自社業務での実習（90分）④ 明日から使う業務を1つ決める（30分） |
| 事後 | アンケート集計と、研修で出た「使えそうな業務」の一覧を担当者に渡す。**1か月後に利用状況を確認**し、必要ならAI導入支援を提案 |

**注意**：受講者のPCで実習する場合、会社が許可したAIサービスとアカウントだけを使ってもらう。

### 3-3. 自主開催の少人数勉強会

- 会場：台東区の区民館・会議室、レンタルスペース、またはオンライン（Google Meet）。
- 申込：Peatix などの受付サービス、またはGoogleフォーム＋事前振込。
- 参加者は経営者が中心でも、**参加費をネットで受け付けると「通信販売」として特定商取引法の表示が必要になる場合があります**（`contact-and-address.md` を参照）。
- 毎回、**参加者アンケートで「個別相談の希望」を聞く**。

## 4. AI導入支援

**基本の考え方**：サイトに書いているとおり「小さく始める」。**1つの業務で効果を出してから広げる**。最初から大きなシステムを作らない。

```
① AI活用診断 → ② 利用ルールづくり → ③ 小さく試す → ④ 社内に広げて定着
   2〜4週間        2〜4週間（①と並行可）   1〜2か月       3か月〜（顧問契約）
```

### ① AI活用診断（2〜4週間）

1. **キックオフ面談（90分）**：経営者と、実際に業務をする担当者の両方に話を聞く。
2. **業務の棚卸し**：1日・1週間・1か月の主な業務を書き出し、**時間がかかっている業務、特定の人に頼っている業務**を探す。
   - 例：見積書の作成、契約書の確認、日報の作成と集計、問い合わせへの返信、議事録、マニュアル作り
3. **評価**：各業務を次の3つで点数をつける。
   - 効果（どれだけ時間が減るか、ミスが減るか）
   - やりやすさ（今あるAIサービスで済むか、データがそろっているか）
   - リスク（顧客情報や機密を扱うか、間違ったときの影響）
4. **報告会（60分）**：提案書を渡す。内容は「すぐ始める業務を1〜2つ」「そのための手順と費用」「ルールの必要性」。

**成果物**：AI活用診断の報告書（10枚程度）

### ② 生成AI利用ルールづくり（2〜4週間）

社内で生成AIを使う前に、**最低限ここだけは決める**：

- 使ってよいAIサービスと、契約形態（会社名義の法人向けプランが望ましい）
- **入力してはいけない情報**（顧客の個人情報、取引先の機密、未発表の情報など）
- AIの回答をそのまま使わず、**人が確認する**場面（お客様への文書、数字、契約に関わるもの）
- 著作権・他社の権利への配慮
- 困ったときの相談先、ルールの見直し時期

参考：経済産業省・総務省の「AI事業者ガイドライン」や、日本ディープラーニング協会（JDLA）の「生成AIの利用ガイドライン」のひな形があります（最新版を確認して使う）。

**成果物**：利用ルール（A4で2〜4枚）＋社員向けの説明会（30〜60分）

### ③ 小さく試す（1〜2か月）

1. **対象業務を1つに絞る**（①の診断で選んだもの）。
2. **今の状態を数字で測る**：1件あたりの時間、月の件数、ミスの数。**これを測らないと効果が説明できません。**
3. **既存のAIサービスで試す**：ChatGPT、Gemini（Google Workspace に含まれる場合あり）、Microsoft Copilot など、**お客様がすでに使える・契約しやすいもの**から。
   - 指示文（プロンプト）のひな形、手順書を作る
   - 必要に応じて、Excelやスプレッドシートとの連携など、小さな工夫を加える
4. **2〜4週間、担当者に実際に使ってもらう**。週1回、困りごとを聞いて直す。
5. **効果を測って報告**：「1件30分→10分、月20件で約6.7時間の削減」のように示す。

**成果物**：手順書、指示文のひな形、効果測定の報告書

### ④ 社内に広げて定着（3か月〜、顧問契約で）

- 試した業務を他の担当者・部署に広げる。社内に「AI係」を1人決めてもらい、その人を育てる。
- 月1回、使われているか・困りごとはないかを確認し、次の業務を選ぶ。
- **最終目標は、HAL経営相談室がいなくても社内で回る状態**。

### AI導入支援で守ること

- **お客様のデータを、武内さん個人のAIアカウントに入れない**。作業はお客様のアカウント・環境で行う。
- **ツールの開発（プログラムを書くこと）は慎重に**。副業で作ると、不具合の対応や保守を長く求められます。最初は「既存サービスの使い方」と「小さな工夫」までにとどめ、本格的な開発は開発会社と組むか、保守の範囲と期間を契約書で決めてから受ける。
- **勤務先で作ったツールや、そのプログラム・ノウハウの資料をそのまま使わない**（勤務先の権利になっている可能性が高い。詳しくは「7.」）。
- 「必ず○時間減る」とは約束しない。効果は試してから示す。
- 設備投資やツール導入の費用がかかる場合は、**デジタル化・AI導入補助金（旧IT導入補助金）などが使えないか**をあわせて検討する（→「5.」）。

## 5. 補助金活用支援

### できること・できないこと（最重要）

| HAL経営相談室がやること（○） | やらないこと（×） |
|---|---|
| 事業に合う制度があるかの確認、公募要領の読み方の説明 | 申請書類を代わりに作成すること |
| 事業計画の考え方の整理（何をして、なぜ、どれだけ良くなるか） | 電子申請（jGrants）の代理入力・提出 |
| 数字（売上、費用、効果）の検討への助言 | 「採択保証」「必ず通る」と言うこと |
| お客様が書いた計画への意見・改善点の指摘 | 採択額に連動した成功報酬（当面は固定報酬のみ。`pricing.md` 参照） |
| 採択後の進め方（発注、支払い、報告）の助言 | 交付申請・実績報告の書類を代わりに作ること |

- 2026年1月施行の改正行政書士法で、「いかなる名目によるかを問わず」報酬を得て書類を作ることが行政書士以外には禁止だと明確になりました。**「名目はコンサル料、でも中身は書類作成」は通用しない**と考えてください。
- 書類作成まで必要なお客様のために、**信頼できる行政書士を1〜2人見つけておく**と安心です。
- ⚠️ どこまでが「助言」でどこからが「書類作成」かは、事実関係によって判断されます。**開業前に行政書士か弁護士に、この進め方を確認してください。**

### 進め方（公募締切から逆算）

| 時期 | やること |
|---|---|
| 締切の2〜3か月前 | 制度の確認、**GビズIDプライムの取得**（お客様が行う。発行まで時間がかかることがある）、見積の取り寄せ開始 |
| 締切の1.5〜2か月前 | 事業計画の骨組みを一緒に考える（3〜4回の面談） |
| 締切の1か月前 | お客様が計画書を書き始める。HAL経営相談室は内容に意見を出す |
| 締切の2週間前 | 最終確認の面談。数字の整合性、要件を満たしているかの確認（チェックリスト） |
| 締切の1週間前 | **お客様が提出**（締切直前はシステムが混むので余裕を持つ） |
| 採択発表後 | 交付申請、発注・支払いの注意点の助言。**交付決定前に発注すると補助の対象外になる制度が多い**ので、必ず伝える |
| 事業期間中〜終了後 | 実績報告・事業化状況報告に向けた助言（何年か続く制度もある） |

### 最初の面談で必ず伝えること

- 補助金は**審査があり、採択されないこともある**。
- 原則として**後払い**。先に全額を支払う資金が必要（資金繰りの確認）。
- 採択後も**報告の義務**があり、要件（賃上げなど）を満たさないと返還を求められる制度もある。
- 制度は毎年変わる。**IT導入補助金は2026年度から「デジタル化・AI導入補助金」に名称が変わり、賃上げ計画などの要件が重くなった**との解説があります。必ずその年の公募要領で確認する。

### 将来の検討事項

- **認定経営革新等支援機関（認定支援機関）**の登録：一部の補助金や融資で、認定支援機関の関与が求められます。中小企業診断士は申請できる立場ですが、要件と手続きは中小企業庁のページで確認してください。
- **デジタル化・AI導入補助金のIT導入支援事業者**：ITツールを提供する事業者として登録する制度です。個人の副業では負担が大きいので、当面はお客様と登録事業者をつなぐ立場が現実的です。

## 6. 顧問契約

**目的**：月に1〜2回、経営者の「相談相手」として定期的に関わり、AI導入や計画の実行を継続して支える。

### 契約前に決めること（契約書に書く）

- 毎月の面談の回数・時間・方法（訪問かオンラインか）
- メール・チャットでの相談の範囲（例：「返信は原則2営業日以内」「平日夜と土日に対応」）
- **料金に含まれないもの**（研修、計画書の大幅な作り込み、補助金の事業計画づくり支援などは別料金）
- 契約期間（最初は3〜6か月）、更新、解約の申し出時期（例：1か月前）
- 秘密保持

### 毎月の流れ

| 時期 | やること |
|---|---|
| 面談の3日前 | 前回決めた「次にやること」の進み具合を、メールで聞いておく |
| 面談（60〜120分） | ① 先月の振り返り ② 今月の相談テーマ ③ 次の1か月でやること（担当者と期限）|
| 面談の翌日まで | 議事メモ（A4で1枚）を送る |
| 月末 | 翌月分の請求書を送る |
| 3か月ごと | 「振り返り面談」で、成果（数字）と次の3か月の目標を確認。続けるか、内容を変えるかも話す |

**ポイント**：顧問契約が続くかどうかは、**毎月「何が前に進んだか」が目に見えるか**で決まります。議事メモに必ず「できたこと」を書く。

## 7. 副業として運営するときの注意

### 勤務先との関係

- [ ] **就業規則の副業・兼業の規定を確認**し、届け出や許可が必要なら手続きする
- [ ] **勤務先と競合する仕事、勤務先の取引先からの依頼は受けない**（利益相反を避ける）
- [ ] **勤務先の情報・資料・プログラムは使わない**。勤務時間中に作ったツールは、勤務先の権利である可能性が高い。HAL経営相談室では、**同じような考え方で、新たにゼロから作る**
- [ ] 勤務時間中に副業の連絡・作業をしない。勤務先のPC・メールを使わない
- [ ] サイトや資料では勤務先の社名を出さない（今の方針どおり）。「大手メーカー」の表現にとどめる

### 時間の使い方

- 対応時間を決めてサイトや契約書に書く（例：「平日19時〜21時、土曜10時〜17時」）。
- 平日昼に連絡が来ても、**夜にまとめて返信**で問題ありません。最初にそう伝えておけば、お客様も困りません。
- 補助金の締切前は作業が集中するので、`pricing.md` の上限を守る。

### 税金・手続き

- [ ] 税務署に**開業届**（屋号「HAL経営相談室」）と、**青色申告承認申請書**を出す（青色申告は65万円控除などの特典。帳簿づけが条件）
- [ ] 会計ソフト（freee、マネーフォワードなど）で、事業用の口座・カードを分ける
- [ ] インボイス登録の要否を検討（`pricing.md` のメモ参照）
- [ ] 副業の所得が年20万円を超えると確定申告が必要。**住民税の徴収方法を「自分で納付（普通徴収）」にする**と、勤務先に副業の所得が伝わりにくくなる（ただし自治体の扱いによる）
- ⚠️ 細かい点は税理士か税務署に確認してください。

### 万一への備え

- **賠償責任保険**：コンサルタント向けの賠償責任保険があります。中小企業診断士協会の会員向けの保険制度もあるので、協会への入会とあわせて確認すると安心です。
- **個人情報の扱い**：問い合わせフォームで名前・連絡先を集めるので、**プライバシーポリシー**をサイトに載せる。
