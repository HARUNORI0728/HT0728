# 脚本 — 第9章・第10章

『フィットア奪還戦記』第9章・第10章の脚本（本作書き下ろし）。筋は design/plot.md §2 の第9章・第10章に従う。終章のあと（告白・後日談・エピローグ）は design/script-endings.md。

## 書式

- 書式の規則は design/script-ch1-2.md の「書式」の節と同じ（`###` 見出しに場面名と条件、`話者｜表情｜本文`、`BGM：`、`（地の文）`、心の声は全体を（　）で囲む）。
- 各場面の見出しのすぐ下に `BGM：` を1行、その次に `背景：` を1行書く。背景名は design/asset-orders.md「2. 背景」か plot.md §6.4 のファイル名。戦闘中の会話は `背景：なし`。台詞の間に書いた `BGM：` `背景：` は、そこで切り替える。
- `一枚絵：<ファイル名>` の行で一枚絵を出す（plot.md §6.3 のもの）。
- 表情は normal / smile / angry / sad。アリエルだけ dere も使う。敵（ダリウス、ガル・ファリオン、オルステッド、ウォルド）は normal / angry のみ。
- この文書で新しく使う話者名と立ち絵ID：アリエル＝ariel、シルフィエット＝sylphiette、ロキシー＝roxy、ルーク＝luke、ペルギウス＝perugius、ナナホシ＝nanahoshi、ダリウス＝darius、ガル・ファリオン＝gall、オルステッド＝orsted、ウォルド＝apostle（10章終幕から）。「使徒」は撃破まで立ち絵なし（`使徒｜-｜…`）。立ち絵のない話者：私兵、ハンナ。

## 実装担当への注記

### 必要な仕組み

1. **表情 dere（要対応・ビルドが止まる）**：アリエルの dere を9章終幕と10章開幕で使った。`Line.face` は dere を受け付けるが、tools/build-script.mjs の `FACES` に `dere` が無いため、このままでは `npm run check` が「表情「dere」は使えません」で失敗する。`FACES` に `'dere'` を足すこと（dere 以外の表情の制限はそのまま）。
2. **背景と一枚絵の行（M10・M11）**：`背景：<名>` `一枚絵：<名>` の行は、今の build-script では `｜` を含まないため読み飛ばされる。見出し直下の `背景：` は場面の背景、台詞の間の `背景：` はそこでの切り替え、`背景：なし` は戦闘中の会話（背景を出さない）。`一枚絵：` は次の行から一枚絵を出す。一枚絵は場面の終わりか、次の `背景：` 行で消す想定。
3. **段の開始（M8①）**：9章④・10章⑤。条件が入るまでは plot.md §7 どおり `turn` で代用（9章④＝前半終了の次のターン・自軍、10章⑤＝7ターン目・自軍）。
4. **ボス戦闘の相手指定（M8②）**：専用版は番号を末尾に回した。9章⑨＝⑤のエリス版、10章⑨＝②のルーデウス版。扱いは「最初のボス戦闘の相手が指定ユニットなら専用版だけを再生し、汎用版は再生しない。汎用版が先に再生していても、指定ユニットとの初戦闘では専用版を再生する」。
5. **撤退・捕縛**：9章⑥はガルの `retreatAt: 0.5`（M3）で撤退したときの `bossDefeat`。9章⑧のダリウスは `defeat: 'captured'`。
6. **話者の差し替え（M12）**：「使徒」は撃破まで `-`（立ち絵なし）。10章終幕から話者名「ウォルド」を使うので、SPEAKER_IDS に `'ウォルド': 'apostle'` を足す。
7. **10章⑧→終幕**：⑧は `BGM：なし` で終わり、そのまま終幕（白い虚空）へつなぐ。
8. 章の最後の「第N章　クリア」は1〜2章と同じく地の文。10章終幕のあとは script-endings.md のエピローグ前半へ進む。

- 話者が盤面にいないと台詞が飛ぶ前提で、相手の台詞が無くても話が通る順に並べた（9章①のルーク、②のギレーヌ、④のシルフィエットは最後か途中で、飛んでも前後がつながる）。
