# 脚本 — 第3章〜第5章

『フィットア奪還戦記』第3章・第4章・第5章の脚本（本作書き下ろし）。筋書きは design/plot.md §2 の各章「場面の一覧」による。

## 書式

- 書式は design/script-ch1-2.md の「書式」の節と同じ（`###` 見出しと条件、`話者｜表情｜本文`、`BGM：`、ルーデウスの心の声は全体を（　）に入れる）。
- この文書で新しく使う行：
  - `背景：<背景名>`：見出しのすぐ下、`BGM：` の次の行に書く。戦闘中の会話は `背景：なし`（地図の上に重ねる）。台詞の行の間に書くと、そこで背景が切り替わる。
  - `一枚絵：<ファイル名>`：台詞の行の間に書く。次の `背景：` の行か、場面の終わりまで表示する。
- この文書で新しく使う話者名と立ち絵ID：ロキシー＝roxy、エリナリーゼ＝elinalise、シルフィエット＝sylphiette、ルーク＝luke、アリエル＝ariel、サラ＝sara、オーベール＝auber（＝ボス「北帝オーベール」）。オーベールは敵なので normal / angry のみ。
- 立ち絵のない話者：ハンナ、トト（第1章から）、冒険者（第5章。サラの仲間。名前は出さない）、フードの護衛（第4章の開幕だけ。正体を明かす前のシルフィエット）。

## 実装担当への注記

### 必要な仕組み

1. **背景と一枚絵の行**（plot.md §5 の M10・M11）：`背景：<名前>` は見出しの下（`BGM：` の次）で場面の背景、台詞の間なら途中の切り替え。`背景：なし` は戦闘中の会話（地図の上に重ねる）。`一枚絵：<名前>` は次の `背景：` の行か場面の終わりまで表示し、その間は立ち絵を隠す。今の tools/build-script.mjs は `｜` を含まない行を読み飛ばすので、この2種の行を読む処理の追加が要る（今のままでも読み込みは失敗しない）。
2. **3章・戦闘中⑦の出る条件**：エリスとロキシーの掛け合いなので、エリスが盤面にいないときは場面ごと飛ばす（話者を飛ばすだけだと、ロキシーの返事だけが残る）。`TalkEvent` に「この仲間が盤面にいるときだけ」（例：`needs: ['eris']`）を足す。入るまでは、エリスが不在でもそのまま再生してよい（大きな破綻はない）。
3. **4章・戦闘中②と④の順**：②（シルフィエットの初戦闘）はふつう④（4ターン目）より先に起きる。④の後に起きても読める文にしてある。
4. **出撃が任意の仲間の台詞**：3章③のパウロ、3章①の「嫌な男」（パウロに似ている、の含み）は、パウロが未出撃でも話が通るように書いた。パウロの台詞は不在なら飛ばしてよい。
5. **フードの護衛**：4章の開幕だけ、シルフィエットは「フードの護衛」（立ち絵なし）。4章・戦闘中①からは「シルフィエット」として立ち絵を出す（plot.md の指示どおり。プレイヤーにだけ先に正体が分かる）。
6. **話者名**：「冒険者」は複数の冒険者が同じ名前で話す（立ち絵なし）。「オーベール」は SPEAKER_IDS の auber。アリエルの dere はこの3章では使っていない。

### 補足

- ロキシーはルーデウスを「ルーデウス」と呼ぶ。「ルディ」はパウロとシルフィエットの呼び方として残し、4章④の正体判明（「その呼び方」）が立つようにした。
- シルフィエットの一人称は台詞で使っていない。原作は「ボク」のはず（要確認）。plot.md の決め台詞の案は「私」なので、6章以降でどちらにするか決めてほしい。
- 5章の開幕で、plot.md の曲の指定（`daily`）に加えて、逃げてきた冒険者の場面から `crisis` に切り替えた。
- ゼニス・ノルン：3章の幕間で、パウロが「ゼニスは見つからない」「ノルンはミリスの、ゼニスの実家に預けてあり無事」と話す（決定事項4）。ノルンはこの後、パウロが折に触れて気にかける程度でよい。
- ロールズ一家の消息は断定していない（3章の終幕で「名簿に載っていない」、4章ではシルフィエットも触れない）。

### 新しく名前を付けた脇役

なし。第1〜2章のハンナ（5章の幕間）とトト（3章の幕間）を再登場させ、ベルトは台詞なしで名前だけ出した（4章の幕間の苗木をシルフィエットに分けた人）。名前のない話者は「冒険者」「フードの護衛」。

### 仕込んだ縦糸と伏線（後の章の担当向け）

- **欠けた輪の金貨**：3章の終幕でロキシーが「弧が正確すぎる。大きな魔法陣の一部を写し取ったよう」。4章⑥でオーベールの財布にも同じ金貨（撃破＝撤退したときだけ。終幕でアリエルが「その金貨」と受ける）。5章の終幕で結晶の芯すべてから金貨が出て、「誰かが金貨を埋めて残滓を育てている」＝残滓は人為的、と結論。8章のナナホシの解析（転移陣の欠片）へ。3章⑥でロキシーが「残滓は自然にはこんな形に固まらない」と小さな疑問を先に置いた。
- **顔を覚えられない依頼人**：3章の終幕でエリナリーゼが「神の声を聞く者は、人の記憶に残らない」という噂。4章の終幕でアリエルが王宮の「白い相談役」（誰も顔を言えない）。6章のドルガン「白い服の男」、8章の使徒へ。
- **ウォルドの下ごしらえ（ごく軽く）**：3章の幕間で、ルーデウスが「ロアのお屋敷の書庫で、よく本を貸してもらった。あの人は元気だろうか」と思い出す。名前も顔の話もしていない。10章の「ウォルドさん。ロアのお屋敷の、書庫の」で回収できる。不要なら1行消すだけでよい。
- **貴族**：4章の終幕でアリエルが「第一王子派の上級大臣ダリウス」の名を出す。5章の開幕で、アリエルが「王宮は人の住まない土地を『持ち主なし』と記す。持ち主のない土地はダリウスのような者のものになる」と話す（6章の検地官の場面の前提）。
- **6章へ**：5章の終幕でロキシーが「ラノアに手紙を書く。魔道具や魔力の流れに詳しい知り合いがいる」（ザノバとクリフの来訪。名前は出していない）。4章⑥でオーベールが「その首はいずれまた頂きに参上する」（6章の再登場）。
- **ナナホシ**：3章の終幕でロキシーが「ラノアに、仮面をつけて転移を研究している不思議な子がいる」。
- **オルステッド**：5章の終幕で冒険者が「銀髪の背の高い男。魔物を一撃で倒したが、見た瞬間に全員が逃げ出したくなった」。ギレーヌが「会わずに済むならそれがいい」。
- **丘の苗木**：4章の幕間でルーデウスとシルフィエットがブエナ村の丘に苗木を植える（ベルトに分けてもらったもの）。ルーデウス「今度は、どこにも行かせません」。10章の丘の決戦、終章の若葉、シルフィエットの告白と後日談へ。
- **人物の関係の種**：エリスはロキシーを「大先生」と呼ぶ（支援会話ロキシー×エリスのC）。エリナリーゼはシルフィエットに「おばあさまと呼んで」と言う（支援会話のA「おばあさまと自然に呼べる」へ）。エリスとシルフィエットは、張り合いと「かっこいい人だね」で始まる。ルーク×サラは5章の幕間で口説きが空振りし、サラが「どっちも馬鹿ね」と初めて笑う。アリエルは4章で「値踏みの続きはキャンプで」と言い、5章の幕間でシルフィエットに「あの人、いつもああなの？」と聞く（6章の「民」と言い直す場面へ）。
- **主題「今度は逃げない」**：3章は開幕で白い光に体がすくみ、震えたまま踏み出す。⑤でロキシーの「目をそらさないで」に応える。4章はシルフィエットが「名乗るのが怖かった。任務は半分言い訳」と認め、④で名を呼ぶ。5章はサラが仲間を逃がして一人で残った理由を⑤で話す。
