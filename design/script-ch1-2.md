# 脚本 — 序章〜第2章

『フィットア奪還戦記』序章・第1章・第2章の脚本（本作書き下ろし）。src/data.ts の CHAPTERS にある第1章・第2章の intro / outro（仮の会話）を、この文書の内容で置き換える想定。

## 書式

- 場面ごとに `###` 見出しを付け、見出しの行に発生条件を書く。
- 台詞は1行1発言で `話者｜表情｜本文`。
  - 表情は normal / smile / angry / sad。敵のガズとドルガンは normal / angry のみ。
  - 立ち絵のない脇役は `話者｜-｜本文`。地の文は `（地の文）｜-｜本文`。
- 話者名と立ち絵の対応：ルーデウス、エリス、ルイジェルド、ギレーヌ、パウロ、ロッタ、ガズ（＝ボス「野盗頭ガズ」）、ドルガン（＝ボス「傭兵隊長ドルガン」）。
- ルーデウスの台詞で全体が（　）に入っているものは心の中の声。
- 音楽は `BGM：<曲名>` の行で指定する。見出しのすぐ下に書くとその場面の曲、台詞の行の間に書くとそこで曲が切り替わる。曲名は `design/asset-orders.md` の「1. 音楽」のファイル名（title, camp, daily, sad, resolve, mystery, family など）。`そのまま`＝直前の曲を続ける、`なし`＝無音。戦闘中の会話で指定した曲は、会話が終わるとマップの曲に戻る。

## 実装担当への注記

### 必要な仕組み

1. **表情付きの台詞**：`Line` に表情（normal / smile / angry / sad）を追加する（implementation-todo.md の13番と同じ作業）。`（地の文）` は `who: ''`、`-` は立ち絵なし。話者「ガズ」「ドルガン」はボスの立ち絵（野盗頭ガズ、傭兵隊長ドルガン）につなぐ。「野盗」は立ち絵なしの一般兵の台詞。
2. **序章**：戦闘のない会話だけの場面。ニューゲーム開始時に、第1章の開幕より前に一度だけ再生する。前世の場面なので、ルーデウスの台詞は立ち絵を出さない（か暗く表示する）のがよい。
3. **戦闘中の会話（章ごとに、条件ごと一度だけ）**。次の発生条件が要る。
   - ターン開始時：`N ターン目の自軍フェイズ開始時`（1章④⑤、2章②⑧）。
   - 増援の出現時：`増援が出現した直後`（2章③⑤）。出現マスが埋まって増援が次のターンに持ち越されたときは、会話も実際に出現したときに合わせる。ターン番号ではなく増援（`Reinforce`）にひも付けるのが安全。
   - 特定の仲間の初戦闘：`ユニット X が初めて戦闘を行うとき`。自分から仕掛けても、反撃でも、戦闘画面の前に再生（1章①②③、2章①）。
   - ゲストの初回復：`ユニット X が初めて杖で回復したとき`。回復の演出の後に再生（2章④）。
   - ボス戦闘前：`ボスと初めて戦闘になるとき`。どちらが仕掛けても戦闘画面の前に一度だけ再生（1章⑥、2章⑥）。
   - ボス撃破時：撃破の演出の直後（1章⑦、2章⑦）。ガズは死なずに捕まる扱い（終幕で縛られて登場する）。ドルガンは「撤退」扱いで、撃破後も8ターン目までは続く。2章⑦は撃破したときだけ再生する。2章の終幕はドルガンを撃破していてもいなくても通じる。
   - 同じ戦闘で複数の条件が重なったら、仲間の初戦闘 → ボス戦闘前 の順に再生する。
   - 話者が戦線離脱しているときは、その人の台詞を飛ばす（systems.md の離脱の扱いと同じ）。1章はルーデウスとエリス、2章はルーデウスとパウロが倒れると敗北なので、この人たちの台詞は必ず出る。
4. **幕間**：章の終幕のあと、拠点画面に入る前に再生する。再生の順は「終幕 → 幕間 → 支援会話 → 拠点」とする。見た幕間は `seenTalks` に記録して、拠点の天幕から見返せるようにする。
5. **置き換え**：data.ts の第1章・第2章の `intro` / `outro` を、この文書の「開幕」「終幕」で置き換える。章の最後の行の「第N章　クリア」は、これまでどおり地の文として扱う。

### 仕込んだ縦糸と伏線（後の章の担当向け）

- **縦糸（黒幕の痕跡）**：1章で、野盗の装備が新品で揃いすぎている → ガズに金と装備を渡した外套の依頼人は、三度会っても顔を思い出せない → 金貨の縁に「欠けた輪」の刻印。2章で、私兵が持っていた金貨にも同じ刻印 → 雇い主は伯爵の家令。家令に金を渡した者の顔も誰も覚えていない → ドルガンが「金は伯爵の懐から出たものではない。もっと奥だ」と言う（撃破したときだけ）。使徒の名前は出していない。「欠けた輪」の刻印は、のちの章（7章の資金の出どころ、8章の迷宮の核など）で使える。
- **伏線**：シルフィエット（1章・幕間。ロールズの娘、丘の木、緑の髪の友だち）と、アリエルの来訪（2章・幕間。王都からの使いと「白い髪の護衛」）を、4章の正体判明につながるように置いた。もう一つ、ロキシー（2章・幕間。東の森で魔物を調べる「青い髪の小柄な魔術師」）を、3章の導入として置いた。
- **主題「今度は逃げない」**：1章は開幕で「林まで下がりましょう」と一度は引きかけ、子どもの泣き声で踏みとどまる。2章は②でパウロに八つ当たりの言葉をぶつけてしまい、⑤で父を置いて逃げかけたところで撤回する。そして終幕で自分から謝る。
- **苦さの下ごしらえ**：1章の終幕で、ギレーヌはボレアス家の消息について何かを知っている素振りを見せ、エリスは「今は聞かない」と約束する。9〜10章でエリスが家族の死を受け止める場面につなげる。
