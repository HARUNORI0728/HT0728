# 脚本 — 恋愛パート（ふたりの時間・嫁同士の会話の追加・戦闘中のひとこと）

『フィットア奪還戦記』の恋愛パートの追加分（本作書き下ろし）。告白で結ばれた相手との短い日常の場面「ふたりの時間」、嫁同士の会話の11〜15、結ばれた相手の戦闘中のひとこと。告白・後日談は design/script-endings.md、嫁同士の01〜10は design/script-supports-wives.md。

## 書式

- 書式の規則は design/script-ch1-2.md の「書式」の節と同じ（`###` 見出し、`話者｜表情｜本文`、`（地の文）｜-｜本文`、ルーデウスの心の声は全体を（　）で囲む）。見出しのすぐ下に `BGM：`、その次に `背景：` を1行。
- 表情は normal / smile / angry / sad / dere。dere の立ち絵がまだない人は、ゲームが smile（それもなければ normal）で代わりに出す。
- **ふたりの時間**：`### ふたりの時間・<名前>・<番号>「<題>」　条件：<解放条件>`。告白で結ばれた（「応える」を選んだ）相手とだけ、キャンプの「ふたりの時間」タブで見られる。解放条件の書き方：
  - `告白の後` … 告白に応えた章間から。
  - `告白のN章後` … 告白に応えた章間から、N章クリアした後。
  - `第N章のクリア後` … 第N章のクリア後の章間から。
  - どれも、同じ相手の一つ前の番号を見たあとで解放される。物語を最後まで終えたら、残りはすべて解放される。
- **嫁同士**：書式は design/script-supports-wives.md と同じ。組を `A×B×C` と3人並べたものは、その3人全員と結婚しているときだけ見られる。
- **戦闘中のひとこと**：`### 戦闘・<名前>・隣接`（結ばれた相手とルーデウスが隣り合って戦ったとき。章ごとに一度）と `### 戦闘・<名前>・撤退`（結ばれた相手が倒れたとき）。盤面にいない話者の行は飛ばす。
- 登場人物は全員成人。恋愛の表現は、照れ・手をつなぐ・寄り添う・将来の話まで。
