# 脚本 — 支援会話（結婚候補）と嫁同士の会話

『フィットア奪還戦記』の、ルーデウスと結婚候補7人の支援会話（C・B・A）と、嫁同士の会話イベント10本（本作書き下ろし）。筋は design/plot.md §3.4・§4、告白（支援S）は design/script-endings.md。

## 書式

- 書式の規則は design/script-ch1-2.md の「書式」の節と同じ（`###` 見出し、`話者｜表情｜本文`、`（地の文）｜-｜本文`、ルーデウスの心の声は全体を（　）で囲む）。見出しのすぐ下に `BGM：`、その次に `背景：` を1行。台詞の間の `背景：` はそこで切り替える。
- 見出しの形：支援会話は `### 支援・ルーデウス×<相手>・<C|B|A>`、嫁同士は `### 嫁同士・<2桁の番号>　<組>「<題>」　条件：<発生条件>`。
- 表情は normal / smile / angry / sad。アリエルだけ dere も使う。立ち絵のない話者：トト、ハンナ。
- ルーデウス×エリスのCは src/data.ts の既存の会話（TALK_RUDEUS_ERIS_C）を使うので、この文書にはBとAだけを置く。
- 支援会話は、相手の加入章（エリス1章、ロキシー3章、シルフィエット・アリエル4章、サラ5章、リニア・プルセナ7章）までの出来事だけを前提にしている。どの時点で見ても矛盾しない。
- 嫁同士・09と10は、結婚相手の組み合わせによらない共通台本。**結婚していない候補の行は飛ばして再生する**（戦闘中の会話で、盤面にいない話者の行を飛ばすのと同じ扱い）。どの行が飛んでも話が通るように書いてある。
