# Q-01・Q-02 納品と検証

2026-11-15 / Codex、SOL分担。

## Q-01：第9・10章

第9章は城壁の南で6ターン防衛し、ペルギウス加入後に北の館を制圧。第10章はオルステッドを撃破せず6ターン耐え、ゲスト共闘・楔からの増援を経て使徒を倒す。最終章の `ending: true` を設定した。24×16の地形画像は `art-samples/map-ch9.png` と `map-ch10.png`。これらは地形のみの確認画像で、ユニットや目印などゲーム側の重ね描きは含まない。

独立レビューを踏まえ、指定ターンを省略しない `strictTurns`、掌打の必殺無効、敵の使徒の顔を戦闘前に見せない処理、苗木の目印を追加。最終戦でも支援・告白を処理してから結末へ進み、クリア直後に閉じたセーブから「結末へ進む」で再開できるようにした。

### 検証と限界

- `tools/test-final-chapters.mjs 24`：配置・地形通行・到達性・武器適合・場面IDを検査。章ごとの24乱数系列で第9章20勝／24、第10章21勝／24。成功時は9章13〜19ターン、10章12〜21ターン。全18戦闘場面の発生を試行群全体で確認（専用／汎用会話は排他的なので一回のプレイで全て出すものではない）。
- 第9章の部隊・経験値・絆を引き継いで第10章へ進む連結6系列は6勝／6。詳細は `q01-simulation-results.json`。
- 味方の能力を直接上書きせず、通常の `addExp` で想定到達レベル13／15へ育成して検証した。第1章からの10章通し育成を再現した検証ではない。簡易AIは治癒役を失いやすく、実プレイヤーの勝率を表す数値でもない。
- `tools/test-strict-holdout.mjs`：耐久の早期終了防止、敗北優先、既存章の早期全滅勝利維持、目標表示、使徒の顔非表示、掌打の一撃必殺回避を検査。
- ブラウザーで両章の地形を目視。開発用の最終章クリア直後状態から、再開ボタンが有効になり、クリックで結末を経てクリア済みタイトルに戻ることを確認（早送り使用）。通常速度での全戦闘UI通し・実聴取は残件。

### 追加の提案

Q-06では第1章からの実際の成長で到達レベルを確認したい。今回の簡易AIではクリフ・ザノバが倒れやすく、配置・回復判断・難度のどれが原因かを実プレイで分けて評価する。数値だけを理由に大幅な弱体化はしていない。

## Q-02：敵のマップ用絵7点

`assets/units/` に鳥、残滓の影、結晶、私兵重騎士、残光の大熊、森の主、バラクを指定名で納品。すべて1254×1254 RGBA PNG。既存の絵柄を参照して組み込み画像生成で作成し、透過・全身と武器の収まり・64/96pxでの識別を確認。数値記録は `q02-art-qa.json`。

素材登録だけでは魔物が `enemy_bandit_*` を探していたため、`imageKey` を発注名に対応させた。今回のビルドで7点の256px WebPとマニフェストも生成し、音楽24曲とともに取り込んだ。顔の立ち絵（バラク等）はQ-02の7点には含まれない。
