# Q-04 会話背景の照合（2026-11-15）

Q-04 着手時点の台本、発注書、画像、ゲームの表示処理を照合した。台本中の背景指定を、各場面の冒頭と途中切り替えを含めて集計した。

## 納品と表示

- 第1便の `title`、`grassland_day`、`camp_day`、`camp_night`、`tent_inside`、`ruined_village` は、元 PNG、配信用 WebP、`BG_ART` のキーが一致。 `title` はタイトル画面で直接使用する。
- 下表の背景14種は、着手時点では対応する PNG、WebP、`BG_ART` 項目が未納。台本の既存名は発注書と一致する。ゲームは背景が未納、または画像を読み込めないときに色のグラデーションを表示する。台本の「背景：なし」は会話用背景を外し、背後の画面を表示する。
- `assets/backgrounds/<ID>.png` を仕様どおり16:9、1920×1080以上で納品し、人物と文字を除き、画面下3分の1を台詞枠用に簡素でやや暗くする。ビルドで横幅1280pxのWebPと `src/art-manifest.ts` の `BG_ART` を生成する。検品では実際に WebP とキーが生成され、冒頭指定と途中切り替えの両方で絵が表示されることを確認する。

## 発注の抜けと差し替え

1. 先行3点は `forest`、`forest_residue`、`buena_hill`。森2点は地形と構図をそろえ、結晶と白い光柱で異常を見せる（asset-requests の指定）。
2. `boreas_memorial` は Q-04 の一覧から漏れている。9章幕間が今もこのIDを要求し、plot §6.4 に夜の邸跡、小さな慰霊の石と花の発注プロンプトがある。asset-requests の優先度3に従って Q-04 に加え、同じ場面の Q-05 `ev_eris_memorial` と月明かり、石、柱の位置を合わせる。
3. `camp_dawn` は Q-04 と BOARD にある。asset-requests に「朝夕の向き・色温度を区別する差分」という指示があり、個別プロンプトと台本参照はまだない。10章開幕は「夜明け前」であり、plot の指定どおり `camp_sunset` を暫定指定している。現状は `camp_sunset` 自体も未納なのでグラデーションになる。朝版は同じ難民キャンプの外れを、低い地平線の淡い朝光、冷たい青灰色、残り火で描く案。納品と同じタイミングで台本担当が10章開幕の背景指定を朝版に替える。他31件の指定がある夕景は別途納品する。

## Q-11 戦闘マップ制作に必要な準備

- 先に第1章（16:11、推奨2048×1408）と第8章（3:2、推奨3072×2048）で試す。各 `chNN-guide.png` を画像生成の参照に使い、同じ縦横比で1マス96px以上を目安にする。第8章は石床と岩壁の境目、北の3マス出口、開始時点の通路を保つ。
- 川・橋・壁・道・森などを動かさず、真上に近い視点を保ち、格子線・文字・人物・枠を入れない。崩落、柵破壊、開門がある章も開始時の地形を描き、変化後のマスはゲームが描き直す。
- `chNN-grid.png` を重ねて通行不可マスと境界を検品し、`assets/maps/chNN.png` として組み込んだあと、ゲームの格子、タップ時の地形名、移動範囲で確認する。試作2枚が通れば残り8章を作る。
- 下絵は迷宮描画の直近の修正より前に生成されている。地形や描画が更新された章は最新版をビルドしてから下絵・検品用画像を再出力する。書き出しツールが使う Playwright は現在の作業環境で解決できず、実行時は利用できる環境を用意する。Q-11 は BOARD に記載があり、作業キューにはまだ行がない。

詳細は [戦闘マップ発注文](../map-paint-prompts.md)、[下絵の書き出し処理](../../tools/map-guides.mjs)。
