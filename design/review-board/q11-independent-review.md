# Q-11 戦闘マップ試作の独立確認

座標はゲームと格子画像に合わせて左上を `(0, 0)` とする。プロトタイプは検討用。元の地形データ、格子付き下絵、実画面の移動範囲を照合してから採用する。

## 第1章「帰郷」

16列×11行。最低1536×1056、推奨2048×1408。確認対象は [下絵](../map-guides/ch01-guide.png)、[格子](../map-guides/ch01-grid.png)、[章データ](../../src/chapters/ch01.ts)。

| 確認箇所 | 地形データと照合する点 |
| --- | --- |
| 川と橋 | 川は `x=9, y=0–6`、南へ曲がって `x=10, y=6–10`。 `(9,4)` だけ木橋、`(10,8)` は石の浅瀬。橋の両端 `(8,4)/(10,4)`、浅瀬の両端 `(9,8)/(11,8)` を道につなげ、ほかの川に渡れる見た目を作らない。曲がり角の `(10,5)` と `(9,7)` は陸地。 |
| 西側の城壁 | `y=4` の `x=0,1,3,4,6` は城壁、`x=2,5` は通れる廃墟。崩れた箇所を壁で閉じない。 `x=7` からは橋へ続く道。 |
| 砦と道 | 砦は `(13,2)`、入口の道は `(13,3)` から `(13,4)`。山は歩兵に限り移動コスト4で通れる。砦を山の中に埋めたり、道と橋の接続をずらしたりしない。 |
| 森・天幕・畑 | 北西の森は `y=0:x=0–2`、`y=1:x=0–1`、`y=2:x=0`。東の森は `y=5–6:x=14–15` と `(15,7)`。南西の天幕は `(1,6),(3,6),(0,7),(2,7),(4,7),(1,8),(0,9),(4,9)`。畑は `y=7–8:x=12–14` と `y=9:x=12–13`。これらの境界と、近接する茂みを格子で見分ける。 |

**試作検品**　[第1章の試作](../../art-samples/q11-ch01-prototype.png)を格子なしと16×11の格子付きで目視した。1512×1040、1マスあたり約94.50×94.55px。16:11に近く、指定の96px/マスには届かない。橋と浅瀬の中心、道のつながり、城壁の廃墟2箇所、砦の入口に大きなずれは見当たらない。湾曲部の川岸は `(10,5)` と `(9,7)` の草地の角にかかり、橋の端も隣の道の一部にかかる。 `(13,6)` の茂みと `(14,6)` の森は樹冠が続いて見えるので、境目の地形名をゲーム内で確認する。

## 第8章「残滓の迷宮」

24列×16行。最低2304×1536、推奨3072×2048。確認対象は [下絵](../map-guides/ch08-guide.png)、[格子](../map-guides/ch08-grid.png)、[章データ](../../src/chapters/ch08.ts)。

| 確認箇所 | 地形データと照合する点 |
| --- | --- |
| 北の出口 | 出口は `(11,0),(12,0),(13,0)` の3マス。中央は石床、両脇は地上の草地。 `x=11–13,y=1` から北の大広間へつながる。 `(10,0)/(14,0)` は森。開口部を1マスに狭めず、その外側に別の出口を描かない。 |
| 西の迂回路 | `x=1–3,y=6–12` の西坑道から `y=5` を横切るとき、`(1,5)` は浅瀬、`(2,5)` は南北向きの橋、`(3–5,5)` は水。`(3,10)` にも通れる浅瀬がある。岩壁 `x=4,y=6–10` と中央の岩塊を挟み、南の核の間から西を回って北へ抜ける形を保つ。 |
| 東の近道 | 核の間の東から `(15,12)→(15,11)→(16,11)→(16,10)→(16,9)` と曲がって東の広間へつながる。 `(15,10),(16,12),(17,10)` は岩壁。北側は `(18,4)→(18,3)→(17,3)` の順で北の大広間へ向かう。 `(17,4)/(17,5)` は岩壁、`(17,3)` は迷宮の主の配置マス。 |
| 中央の水と岩 | 中央の湖は `y=5:x=10–12`、`y=6:x=7–13`、`y=7:x=6–13`、`y=8:x=7–12`、`y=9:x=10–11`。岸に隣接する山（歩兵が通れる岩棚）、崖、岩壁を同じ見た目で塗りつぶさない。 `(12,4)` は広間から湖畔へ1マスの石床が伸びる。東の `(20,5)/(20,6)` は別の小さな池で、周囲の広間を横切る通路と区別する。 |
| 崩落と出撃地点 | 南中央の核の間（出撃地点 `x=10–13,y=12–14`）と双方の経路は開始時点の姿を描く。4ターン目 `y=13–15`、7ターン目 `y=10–12`、10ターン目 `y=7–9` の対象地形はゲームが岩壁で上書きする。 |

**試作検品**　[第8章の試作](../../art-samples/q11-ch08-prototype.png)を格子なしと24×16の格子付きで目視した。1536×1024、3:2、64px/マスで指定の96px/マスに届かない。北の3マス出口、西の浅瀬と橋、東の屈曲部、北大広間への接続、東の小池に経路を変える大きなずれは見当たらない。湖の縁は `(12,4)` の石床の南端に少しかかる。 `(15,11)` は坑道の木枠が石床の角に重なるが、曲がり角は読み取れる。岩棚と岩壁の区別および崩落後のつなぎ目はゲーム内で確認する。

## 採用時の確認

絵に格子を重ね、表の重要地点を比較する。地形の移動や追加で見かけ上の通路が変わる場合は修正する。今回の目視は表の主要地点を対象とし、全マスの境界一致とゲーム内動作は未検証。2枚は試作の状態で、採用には指定解像度を満たす絵で再照合し、ゲーム内でタップ時の地形名と移動範囲を確認する。手順の出典は [戦闘マップ発注文](../map-paint-prompts.md)。
