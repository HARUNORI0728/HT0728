## SC-01：18歳と「転移から三年」の年表を明文化する（優先度：高）

`world.md` の主人公18歳に対し、`script-ch1-2.md:48` は転移後三年、`:58` は魔大陸を発って三年、`:195` は十八歳とします。出発時期の異なる出来事が同じ期間で語られています。公式アニメ第8話は転移前の10歳の誕生日を扱っており、原作の発生年齢を保つなら転移から三年では18歳になりません。

提案：18歳を維持した年表を作り、転移年齢をIFとして変えたのか、経過年数を変えたのか確定する。父との別離、魔大陸出発、剣の修行開始はそれぞれ起点が違うため、「三年」を一括置換しない。支援台本にも三年前／三年ぶりがあるので同時に確認する。

根拠：[公式アニメ第8話](https://mushokutensei.jp/story/8/)。判定：原作年齢を維持する場合の矛盾／IF年表の説明不足。

## SC-02：龍神への恐怖と呪いの例外を区別する（優先度：高）

`script-ch9-10.md:164–166` の一同の恐怖に続くルーデウスの身体反応、`:194` のナナホシの「見るだけで逃げたくなる」は、両者まで呪いに影響されているように読めます。原作ではルーデウスが他者と同じ反応をしないことが重要です。強さや過去の経験への通常の恐怖は成立するため、怖がる台詞をすべて消す必要はありません。

提案：「呪いではなく、実力を知っているため怖い」と読める理由を添える。ナナホシについても原作基準を確認して例外を明文化する。終盤でルーデウスだけが礼を言いに近づく場面とのつながりを保つ。

参考：[著者Web版・第六十話](https://ncode.syosetu.com/n9669bk/67/)。判定：原作設定の取り違えにつながる表現、要確認。Web版の作中人物の説明を全知の設定解説と同一視しない。

## SC-03：孫と再会した後にも探している支援会話（優先度：高）

`script-ch3-5.md:303–305` でエリナリーゼはシルフィエットを孫と認識します。一方 `script-supports-1.md:312–338` のルーデウスとのB/A会話は、孫の生存確認・捜索をまだ続ける前提です。`src/main.ts:694` と `src/story.ts` の `supportScene` はペアとランクで台本を選び、再会済み状態で台詞を切り替えていません。支援の進行が遅いプレイで時系列が逆転します。

提案：再会前後の差分を用意するか、発生時期に依存しない内容へ直す。支援そのものを見られなくする解決は避けたいです。判定：内部整合性の問題。

## SC-04：終盤の戦闘から対話への条件が弱い（優先度：中）

`script-ch9-10.md:166` 付近では話を聞かず夜明けの戦闘を予告し、10章では同じ金貨を差し出すことから使徒でないと判断します（`:283–288`）。ナナホシは旧知であるため、戦闘前の仲介が成立しない理由も必要です。

提案：戦闘で何が証明されたのか、あるいは戦闘前に説明できなかった事情を追加する。原作の誤りとは断定せず、物語の因果関係の改善案とします。

## AUDIO-01：父子再会の不安・怒りに comedy（優先度：高）

`script-ch1-2.md:219–230`、2章開幕。再会の `family` から `:225` で `comedy` に変わり、連絡がなかった息子への不安・怒りを描く台詞が続いて敵襲の `crisis` に移ります。切迫した感情が笑いとして聞こえるおそれがあります。

提案：怒りの区間は `family` 継続、抑えた `sad`、または無音を比較し、和解後の軽口に `comedy` を限定する。これは台本からの演出評価で、聴取済みの不具合ではありません。Claudeに狙いを確認してから変更する。

## AUDIO-02：勝敗曲と次の場面の重なり（優先度：高）

`src/main.ts:570–578` は勝利曲を開始後1300msの表示を待って終幕へ進みます。敗北も `:585–586` で1500ms後に次へ進みます。納品曲は約8秒なので、操作・ロード時間によって次の台詞／BGMに残りが重なる可能性があります。`src/audio/engine.ts` のジングル処理は再生中のBGMを絞りますが、次のシーン開始でジングルを止める処理とは別です。ファイル版の終了判定自体は `file.ended` を使っているため、合成曲の長さでファイルを強制終了する不具合とは判断しません。

再現手順：通常速度で1章をクリアし、勝利表示直後の再会会話まで録音・ログ比較する。続いて敗北時の悲しい曲への移行も確認する。提案：実際の再生終了を待つか、場面開始に合わせてジングルを短くフェードする。早送り・ミュート・読み込み失敗でも進行が止まらない設計にする。現時点では静的に確認した重複の可能性で、実機再現待ちです。

## AUDIO-03：曲ごとの音源差（優先度：中）

ファイル納品済みは title / camp / map_dawn / map_enemy / boss / crisis / sad / daily / victory / defeat。ほかの曲は内蔵合成音にフォールバックするため、未納品＝無音ではありません。体験版でも family / mystery / resolve / comedy / prologue が使われ、曲調や音量の連続性を聴き比べる必要があります。追加制作の優先案は別紙参照。
