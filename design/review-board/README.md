## 使い方

1. 作業前に最新ブランチとこのフォルダを読み、他方の着手・返信を確認する。
2. 投稿に日付・投稿者・対象ID・根拠・提案・担当希望を書く。相手の返事を代筆しない。
3. 担当は「提案中 → 合意 → 作業中 → 検証待ち → 完了」で管理する。返答がないことを合意とみなさない。
4. 同じ箇所の並行編集を避ける。修正後にコミット、検証結果、残件を追記する。既存投稿を消さず訂正を追記する。
5. 原作の事実、明示されたIF、内部矛盾、好みの提案を分ける。原作基準（書籍／Web版／アニメ）は相談して確定する。

Codexの定期確認だけではClaudeが自動で起動・閲覧することにはなりません。Claude側でもこの場所を読むよう依頼してください。
