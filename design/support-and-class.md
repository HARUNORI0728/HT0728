# 支援システムとクラスチェンジ — 設計書

world.md 4章・5章を前提にした実装仕様。数値はすべて `src/data.ts` の定数にあり、調整はそこだけで済む。
ルールは `src/logic.ts`（純粋関数）、画面は `src/main.ts`。

## 1. 支援システム

### 1.1 データ

```ts
type SupportRank = 'C' | 'B' | 'A' | 'S';
interface SupportPair { a: string; b: string; max: 'A' | 'S'; tag?: string; start?: number;
                        talks: Partial<Record<SupportRank, Line[]>> }   // data.ts SUPPORTS
type Bonds = Record<string, { pts: number; rank: number }>                 // State.bonds（rank 0=なし 1=C … 4=S）
```

- ペアのキーは2人のIDを辞書順に並べて `+` でつないだもの（例 `eris+rudeus`）。`pairKey(a, b)`。
- `SUPPORTS` に world.md 4章の全組を入れる。**数えると26組**（world.md の「計25組」と合わない。未決事項参照）。
- `start` は初期絆ポイント（師弟・旧知の組に少し下駄を履かせる）。ルーデウス×エリス 10、エリス×ギレーヌ 10。
- `talks` が空、または該当ランクの会話が無い場合は、地の文1行の代替会話を再生してランクを上げる（壊れない）。
- 会話本文は今回、第1章の4人の5組のCランクだけ書き下ろす。

### 1.2 絆ポイントの獲得

- 自軍ユニットが戦闘（攻撃・反撃のどちらでも）を終えた時、そのユニットが生存しており、
  **上下左右に隣接（距離1）している支援相手**が生存していれば、その組に **+10**。
- 1回の戦闘で1組に入るのは1回だけ。隣接相手が2人いれば2組それぞれに入る。
- ポイントは「次に上がれるランクの必要値」で頭打ち（会話を見るまで先に進まない）。
- 必要ポイント（累計）: **C 30 / B 80 / A 150 / S 240**。
  目安：Cは隣接戦闘3回、Bはさらに5回、Aはさらに7回、Sはさらに9回。
- 敗北して章をやり直した場合、その章で貯めたポイントは失われる（章開始時の値に戻る）。

### 1.3 ランクの確定（支援会話）

- 勝利 → 章の結末会話 → **支援会話**（上がれる組を SUPPORTS の並び順に全部、1組につき1ランクずつ）→ 章間画面。
- 上がれる条件：`pts ≥ 次ランクの必要値` かつ 次ランク ≤ そのペアの `max`。
- Sは恋愛。Sに上がるには、2人とも「現在のS相手の数 < 上限」であること。上限は1、**ルーデウスのみ3**（`S_LIMIT`）。
  枠が埋まっている組はポイントがS必要値まで貯まっていても会話が出ない（支援一覧に「S枠なし」と出す）。
- 将来拠点ができたら、章間画面の「支援会話」ボタンから再生する形に移す（判定関数はそのまま使える）。

### 1.4 戦闘補正

- 対象：戦闘する自軍ユニットから **2マス以内**（マンハッタン距離≤2）にいる、生存している支援相手。
- 1人あたりの補正（ランク別）:

| ランク | 命中 | 回避 | 必殺 | 与ダメージ |
|---|---|---|---|---|
| C | +5 | +5 | +2 | 0 |
| B | +10 | +10 | +4 | 0 |
| A | +15 | +15 | +6 | 0 |
| S | +20 | +20 | +8 | +1 |

- 複数の相手がいれば合算し、上限は **命中+30 / 回避+30 / 必殺+15 / 与ダメージ+1**。
- 命中 = 武器命中 + 技×2 + 幸運/2 + 相性 **+ 自分の支援命中** − (速さ×2 + 幸運 + 地形回避 **+ 相手の支援回避**)
- 必殺 = 武器必殺 + 技/2 + 職の必殺補正 **+ 支援必殺** − 相手幸運
- 攻撃側の位置は移動後のマスで判定する。戦闘予測には補正込みの数値と「支援：エリス C」のような内訳を表示する。

### 1.5 画面

- 戦闘中：自軍ユニットの情報欄に「支援」行（相手・ランク・ポイント/次の必要値）。会話待ちは「会話待ち」と表示。
- 隣接戦闘でポイントが入ると、ユニットの上に「絆+10」と表示。
- 章間画面「支援」タブ：加入済みの2人の組だけを一覧。ランク、上限（A止まり／S可）、進捗バー、会話待ち・S枠なしの表示。

## 2. クラスチェンジ

### 2.1 データ

```ts
interface ClassDef { name; mov; mtype; sprite; tier?: 1 | 2; wtypes: WType[];
                     bonus?: Partial<Stats>; crit?: number; gift?: string; desc?: string }
type PromoReq = { kind: 'lv'; min: number } | { kind: 'art'; art: ArtId; min: number };
const PROMOS: Record<string, { to: string; req: PromoReq[] }[]>   // 下級職ID → 上級職の候補
```

- 条件は配列で持ち、すべて満たせば可。今回データに入れるのは `{ kind: 'lv', min: 10 }` のみ。
- `art`（階位・流派）条件は判定関数まで実装済み。ユニット側に `arts?: Partial<Record<ArtId, number>>` を持たせれば有効になる。

### 2.2 ルール

- 条件：下級職（tier 1）で **Lv10以上**。候補が2つある職は選択。
- 実行すると：職が変わる／**Lvは1に戻り、EXPは0**／上級職の `bonus` を能力に加算（HP増分は現在HPにも加算）／
  移動力・移動タイプは上級職の値になる／新しく使える武器種の武器を1本も持っていなければ `gift` の武器（表の「入手武器」）を1本もらう。新しく追加した武器はライトニング（光・威力4・命中95・必殺5・射程1〜2）のみ。
- 経験値計算では上級職のLvを **+10** して扱う（内部レベル。`effLv`）。上級職Lv1は下級職Lv11相当。
- レベル上限は下級・上級とも20。成長率は変えない。
- 職ごとの使える武器種 `wtypes` 以外の武器は、攻撃・反撃に使えない（今の配置では全員一致しているので挙動は変わらない）。
- 下級職の移動力は変更なし。新規の下級職（傭兵など）は移動5、騎士7、重装4、盗賊6。
- 実行場所：**章間画面**の「部隊」タブ。戦闘中にはできない（ギレーヌが第1章開始時点でLv10のため、章中に許すと第1章の難度が変わる）。

### 2.4 階位と流派の扱い（今回は条件に入れない）

- 階位は魔術・剣とも同じ梯子：初級(1)・中級(2)・上級(3)・聖級(4)・王級(5)・帝級(6)・神級(7)。
- 将来の条件案：上級職ごとに `{ kind: 'art', art, min }` を1つ足す。例：剣聖＝剣神流 上級(3)、剣帝＝剣神流 帝級(6)、
  守護剣士＝水神流 上級、剣豪＝三流派いずれか 上級、大魔術師＝いずれかの魔術 聖級、賢者＝治癒 上級＋攻撃魔術 上級。
- 階位の上げ方（未実装案）：章クリア報酬・拠点の「修行場」・特定の支援Aで1段階上がる。初期値は CharDef に持たせる
  （ロキシー 水 王級、ギレーヌ 剣神流 王級 など）。初期値で既に条件を満たす者は Lv だけが関門になる。

## 3. 進行と画面の流れ

```
タイトル ─はじめから→ 章の導入会話 → 戦闘 ─勝利→ 結末会話 → 支援会話（あれば）→ 章間画面
                                       └敗北→ タイトル（章の最初からやり直し）
章間画面: [部隊] ユニット一覧・クラスチェンジ / [支援] 支援一覧 / [次の章へ]（第2章は制作中なので無効）/ [タイトルへ]
タイトル ─つづきから→ 戦闘中のセーブなら戦闘に、章間のセーブなら章間画面に戻る
```

## 4. セーブ

- 保存キーを `fittoa-save-v1` → **`fittoa-save-v2`** に上げる。
- 形：`{ v: 2, battle: State | null, camp: Camp | null }`
  - `State` に `bonds` を追加。
  - `Camp = { next: 次の章番号, cleared: クリア済み章数, roster: Unit[], bonds: Bonds }`
- 戦闘中は毎ターン `battle` を保存（`camp` は直前の章間の値を保持）。勝利で `battle = null`、`camp` を更新。
- v1 のセーブだけがある場合は、`bonds = {}` を補って戦闘中セーブとして読み込む。
