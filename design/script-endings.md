# 脚本 — 告白・後日談・エピローグ

『フィットア奪還戦記』の告白イベント（結婚候補7人）、後日談（7人×結婚／仲間の14本）、全員集合のエピローグの脚本（本作書き下ろし）。筋は design/plot.md §3 に従う。第10章の終幕は design/script-ch9-10.md。

## 書式

- 書式の規則は design/script-ch1-2.md の「書式」の節と同じ（`###` 見出しに場面名と条件、`話者｜表情｜本文`、`BGM：`、`（地の文）`、心の声は全体を（　）で囲む）。見出しのすぐ下に `BGM：`、その次に `背景：` を1行。台詞の間の `BGM：` `背景：` はそこで切り替える。`一枚絵：<ファイル名>` で一枚絵を出す。
- 表情は normal / smile / angry / sad。アリエルだけ dere も使う。
- 告白の最後の `選択：応える｜応えられない` はプレイヤーの選択肢（この行だけは台詞ではない）。そのあとの `#### ▼応える` `#### ▼応えられない` の下が、それぞれを選んだときの続き。
- 告白の一枚絵は design/portrait-prompts.md「イベント絵（告白場面）」の ID をそのままファイル名にした（`assets/events/<ID>.png`）。
- この文書で新しく使う話者名と立ち絵ID：シルフィエット＝sylphiette、ロキシー＝roxy、サラ＝sara、リニア＝linia、プルセナ＝pursena、アリエル＝ariel、ナナホシ＝nanahoshi、ウォルド＝apostle。立ち絵のない話者：トト。
- `### 差し替え・…` `### 差し込み・…` は、条件を満たしたときだけ後日談やエピローグの行を入れ替える・足すための断片（使い方は末尾の注記）。

- エピローグ前半と締めは、誰と結婚していても（0〜3人）成り立つように、家族や同居の話を書いていない。結婚相手に固有の内容は後日談と差し込み行に寄せた。最後の独白の「呼ぶ声」も誰の声か決めていない。
- 後日談同士の矛盾を避けた点：シルフィエット（仲間）とアリエル（結婚）は、どちらも「シルフィエットは王都で護衛」で両立する。リニアとプルセナの仲間版は相手に触れず、二人とも仲間版のときだけ差し込み行で「相棒と二人」を足す。エリス（仲間）は「春の終わり」に発つので、春のエピローグ（イゾルテとの再戦の約束）と矛盾しない。
