# 脚本 — キャンプの日々（天幕の会話・食卓・贈り物）

『フィットア奪還戦記』の章間キャンプ「天幕」タブで見られる、仲間たちの日常の掛け合い（本作書き下ろし）。支援会話（2人）と違い、3人以上が出る場面を中心にした。あわせて、天幕の「食卓」（だれと食卓を囲むか）と「贈り物」の短い反応の台詞もここに置く。

## 書式

- 書式の規則は design/script-ch1-2.md の「書式」の節と同じ（`###` 見出し、`話者｜表情｜本文`、`（地の文）｜-｜本文`、ルーデウスの心の声は全体を（　）で囲む）。見出しのすぐ下に `BGM：`、その次に `背景：` を1行。
- **キャンプの日々**：`### 日々・<2桁>「<題>」　条件：第N章のクリア後`。第N章のクリア後の章間から、天幕の「キャンプの日々」で見られる。
  - 台詞を話す仲間（立ち絵のある仲間16人＋ルーデウス）が全員そろっている（加入していて、クラシックで離脱していない）ときだけ出る。条件に書かなくても、台詞から自動で決まる。ハンナ・トト・ナナホシなど仲間でない話者は条件にならない。
  - 条件に `欠けた仲間の台詞は飛ばす` と書いた場面は、離脱した仲間がいても出て、その人の行だけを飛ばす（決戦前夜の1本）。地の文には、欠けるかもしれない仲間の名前を書かない。
  - 特定の章の出来事に触れる場面は、その章のクリア後にした。
- **食卓**：`### 食卓・<名前>`。天幕の「食卓」で、その人を食卓に呼んだときの一言。台詞のうち1行がランダムで出る。`食卓・ハンナ` は最初の一言、`食卓・ルーデウス` は締めの一言。
- **贈り物**：`### 贈り物・<名前>・好き「<品>」` と `### 贈り物・<名前>・ふつう`。好きな品（src/shop.ts の GIFTS の名前）を渡すと「好き」の行がすべて、それ以外は「ふつう」の行が出る。`{品}` は渡した品の名前に置き換わる。恋愛候補7人の「好き」には dere の一言を入れた。
- 登場人物は全員成人。性的な描写はしない（足湯は服のまま、裾をまくるだけ）。
