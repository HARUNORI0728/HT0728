# 通しプレイによる難易度調整の報告（第1章〜第10章・カジュアル）

## 1. 通しの自動プレイの道具（`npm run playthrough`）

`tools/playthrough.mjs`。src/logic.ts と章データを esbuild で読み込み、main.ts の進行を同じ順になぞる（自軍フェイズ → 敵軍フェイズ〔砦の回復 → AI切り替え → 増援 → 行動〕 → ターン経過・地形変化・砦の回復 → 段の切り替え）。
「はじめから」（カジュアル）の第1章から、章クリア → キャンプ → 次の章を、**実際の成長と持ち越し（`rosterOf`）のまま**第10章のクリアまで進める。会話と演出は飛ばす（会話のフラグは立てるので、どの会話が出たかは記録される）。

- キャンプ：支援会話は飛ばして支援ランクだけ上げる（告白は「応える」）。Lv10 になった仲間はすぐクラスチェンジ（先頭の候補）。
- 出撃準備：推し（シルフィエット・エリス・アリエル）は必ず、回復役を1人、残りは実効Lvの高い順（加入して2章以内の仲間は少し優先）。
- 負けたら、カジュアルの「章の最初から」と同じく、キャンプの名簿で章をやり直す（既定は4回まで。超えたら「stuck」と記録して、入る前の名簿で次の章へ進み、測定は続ける）。40ターンで打ち切り（timeout）。
- 打ち方：各ユニットが動けるマス×行動（攻撃・杖・傷薬・待機・制圧・離脱）を点数で選ぶ。
  - 次の敵軍フェイズに届く敵（AI別：guard はその場、target は次の一歩、aiFrom も考慮）から受けるダメージの期待値と、**倒れる確率**（命中・必殺・追撃を数えた分布）を引く。
  - 敗北条件のキャラとゲストは倒れる確率を重く見て、味方の壁が動いた後でも安全かで判断し、前に出ない・目標へは後ろから付いていく。弓（隣に反撃できない）と回復役も味方の近くに留まる。
  - HP が減ったら下がる・砦に入る・傷薬。回復役は減った味方を治す（敗北条件のキャラを優先）。
  - 止めは「平均よりLvの低い仲間」と推しに譲る（人のふつうの経験値の配分）。まず目の前の敵を片づけ、敵が5体以下か7ターン目以降でボス・制圧マスへ向かう。
  - 守る章は持ち場（食糧庫・本陣・護衛対象のまわり）の半径に留まり、敗北マスには硬い仲間が乗って塞ぐ（6章の食糧庫、9章の本陣、7章の船着き場）。制圧マスは制圧役のために空けておく。離脱の章は、崩落後の地形で出口までの距離を毎ターン計り直す。
- 記録（JSON と表）：章ごとの勝敗、ターン数、やり直し回数、倒れた仲間（ターン・倒した敵の名前とLv）、負け方（`vip:誰` 敗北条件のキャラが倒れた／`tile` 敗北マス／`wipe` 全滅／`timeout`）、出撃メンバーとLv、名簿全員のLv、仲間ごとの戦闘回数・撃破数、受けたダメージ合計、敵の攻撃回数、最低HP率、出た戦闘会話。
- 使い方：`npm run playthrough -- --seeds 10 --seed0 101 --out 結果.json`。`--trace 6` でその章の1手ずつを表示、`--from 6 --camp 結果-camps.json` で保存した名簿からその章だけ、`--root 別のフォルダ` で別の版のソース（調整前など）で測る、`--browser` で Playwright により本物の画面と照合（「はじめから」→カジュアルの第1章の配置と、章間の名簿から始めた次の章の出撃メンバー・能力値が一致するか）。照合は一致した。

**限界**：画面のクリックではなく規則を直接動かす（速さのため。10章×10回で数十秒）。打ち方は人より手際がよい面（全マスを比べる）と下手な面（先読みは1手、囮・壁の組み立てが粗い、守る章で敵将に手を出さない）がある。ターン数は人より短めに出る見込み。出撃メンバーは強い順に選ぶので、控えの仲間（パウロ・ロキシー・エリナリーゼ・ルーク・サラ・ザノバ）は育たない（下の「残った課題」）。

## 5. 残った課題と、人が遊んで確かめてほしい点

残った課題：
- **第1章はまだ短い（4〜6ターン）**。Lv10 のギレーヌと Lv8 のルイジェルドが強すぎ、敵を増やしても反撃で溶ける。勝利条件（全滅）を変えずに延ばすには、古参の加入Lvか1章の敵の質を見直す必要がある（今回は導入の章として許容）。
- **第3・4・7・8章は 8〜10ターン**で、目安の 11〜15 より短い。ただし道具は人より手際がよいので、人では +2〜3 ターンになる見込み。第2・6章は耐久・防衛で固定（9・13ターン）。
- **控えの仲間が育たない**：systems.md §5 の「控えの経験値（出撃した仲間の平均の30%）」が未実装。出撃枠が少なく強い順に選ぶと、パウロ・ロキシー・エリナリーゼ・ルーク・サラ・ザノバは加入時のLvのまま。実装するなら logic.ts の `rosterOf` 付近と main.ts のキャンプ表示が要る（今回は範囲外として触っていない）。
- **アリエル（王女）にはクラスチェンジ先が無い**（`PROMOS` に princess が無い）。ほかの仲間は Lv10 で上級職になるため、後半は相対的に弱い。上級職の追加は data.ts の数値の範囲を超えるので、担当の判断が要る。
- 武器を手に入れる手段が無い（店・宝箱が未実装）ので、仲間の武器は加入時のまま。敵の武器だけが鋼・業物へ上がっていく前提（§6）とずれている。
- 不具合（触っていない）：main.ts の「章の最初から」（`chapterStart`）は出撃準備で選んだメンバーを引き継がず、名簿の先頭から出撃し直す。
- ch2 のドルガン戦の会話（battle6/7）は、耐久をそのまま耐える打ち方では出ない（ドルガンに挑めば出る）。

人が遊んで確かめてほしい点：
1. 第1章：増援（2〜4ターン目）が来ても、序盤の導入として間延びしないか。エリス（Lv3・鋼の剣）が強すぎないか。
2. 第3章：開幕の1ターン、丘の狼が動かないのが不自然に見えないか。残光の大熊（HP50）の硬さ。
3. 第4章：関所の守り（重騎士Lv9・門の剣士・西の壁の槍兵）が重すぎないか。7ターン目の西からの騎馬がルーデウスに当たって理不尽でないか。
4. 第5章：サラが3ターン目まで無事でいられるか。
5. 第7章：バラクの逃走が7ターン目になって、会話（ch7.battle6）の流れとして自然か。HP60のバラクを柵越しに削る手応え。
6. 第6章：クリフ・シルフィエット・エリスが倒れやすい（1回ずつ程度）。北の傭兵の突撃の当たり方。
7. エリスとアリエルが、後半も推しとして戦力に感じられるか（数値上は 10章で Lv15・Lv11）。
