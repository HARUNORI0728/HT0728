# 蒼星のレガリア（仮）— 世界観・設定書

ターン制タクティクスRPG。オリジナル作品。量産作業（会話・データ）を行う際はこの文書を正とする。

## 1. コンセプト

「前世に悔いを残した男が、異世界でもう一度、今度こそ本気で生きる」。
戦記もの（祖国奪還）の骨格に、転生・魔術の階位・多種族・家族と人生という要素を重ねる。

取り入れる要素（いずれも本作独自の設定として構成する）:

| 要素 | 本作での形 |
|---|---|
| 転生主人公 | レンは前世（現代日本の会社員・34歳）の記憶を持って生まれた。誰にも明かしていない |
| 本気で生きる | 前世で家族や仲間から逃げ続けた後悔が、仲間を守る動機になる。支援会話の主題 |
| 魔術の階位 | 初階・中階・上階・聖階・王階・星階の六階位。階位は称号でありクラスチェンジ条件にも絡む |
| 無詠唱 | 通常の魔術は詠唱が必須。レンだけが前世の科学知識で「現象を像として組む」ため詠唱なしで撃てる |
| 剣の三流派 | 紅蓮流（先手必勝）・鏡月流（受けて返す）・蛇尾流（勝つためなら何でも）。スキルの系統になる |
| 多種族 | 人族・長耳族・獣人族・魔族。魔族は「星蝕を呼ぶ」として迫害されている（誤解） |
| 人生と家族 | 恋愛は結婚と後日談まで描く。拠点は「帰る家」として少しずつ賑やかになる |

## 2. 世界

- **大陸アストリア**: 夜空の「蒼星」から降る加護（星脈）が魔術の源。
- **星蝕**: 近年、蒼星が欠けはじめ、魔術が暴走する夜が増えている。
- **ルミナス王国**: 蒼星を祀る小国。王家は「レガリア（星の王笏）」を代々守る。
- **ヴァルド帝国**: 大陸北東の軍事国家。星蝕を止める名目で各国のレガリアを奪っている。
- **黒幕「星喰らい」**: 皇帝の背後にいる存在。実はレンと同じ転生者で、前世に帰るために蒼星の力を喰らい尽くそうとしている。「前世に戻りたい者」と「この世界で生きると決めた者」の対決が最終章の主題。

## 6. システム要約

- **戦闘**: 威力 = 力or魔力 + 武器威力 ± 相性、ダメージ = 威力 − 守備or魔防 − 地形。速さ差4以上で追撃。必殺は3倍。
- **相性**: 剣 > 斧 > 槍 > 剣、理 > 光 > 闇 > 理（命中±15、威力±1）。
- **成長**: 経験値100でレベルアップ。能力ごとに成長率で上昇判定。
- **クラスチェンジ**: Lv10以上＋条件（魔術は階位、剣は流派の免状）で上級職へ。分岐あり。
- **支援**: 隣接して戦闘すると絆ポイント。ランクに応じて隣接時に命中・回避・必殺の補正。
- **難易度**: カジュアル（倒れても次章で復帰）／クラシック（復帰しない）。
