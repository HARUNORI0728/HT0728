# フィットア奪還戦記 — 設定書

『無職転生』の非公式ファンゲーム（個人で遊ぶ用・非公開）。ターン制タクティクスRPG。
キャラクターと世界は原作のものを借り、**物語と会話はすべて本作用の書き下ろし**とする（原作の文章・場面をそのまま写さない）。
量産作業（会話・データ）を行う際はこの文書を正とする。

## 1. コンセプト

原作の「もしも」の物語。転移事件で消えたフィットア領を、ルーデウスたちが仲間を集めて取り戻し、復興させる。
主題は原作と同じく「今度こそ本気で生きる」と「家族」。

- **時期**: 転移事件から数年後。ルーデウス18歳。登場キャラは全員成人として描く。
- **原作との違い（IF）**: 再会の順序と時期が原作と異なる。パウロは存命。結婚はまだ誰ともしていない。
- **敵**: 無人になった領地の利権を狙うアスラ貴族の私兵、野盗、転移の残滓から湧く魔物。黒幕は貴族を唆す「使徒」（本作オリジナルの人物）。

## 4. 支援（恋愛・友情）ペア

S = 恋愛（告白・結婚・後日談）、A = 友情や家族の絆まで。原作の関係を基本にし、本作独自の組は（IF）と記す。

- **ルーデウス**: シルフィエット(S) / ロキシー(S) / エリス(S) / サラ(S・IF) / パウロ(A・親子) / ルイジェルド(A) / ギレーヌ(A) / ザノバ(A・師弟) / クリフ(A) / ルーク(A) / リニア(A)
- **エリス**: ギレーヌ(A・師弟) / ルイジェルド(A) / ロキシー(A) / シルフィエット(A)
- **ロキシー**: シルフィエット(A) / エリナリーゼ(A) / パウロ(A・元仲間)
- **クリフ**: エリナリーゼ(S)
- **パウロ**: エリナリーゼ(A・元仲間) / ギレーヌ(A・元仲間)
- **ルーク**: サラ(S・IF) / シルフィエット(A・元同僚)
- **ザノバ**: リニア(A) / クリフ(A)
- **サラ**: リニア(A)

計25組。Sの上限は1人1相手だが、**ルーデウスだけは原作に合わせて最大3人**（シルフィエット・ロキシー・エリス）とする。
恋愛描写は告白と結婚、後日談まで。性的な描写は入れない。

## 5. システム要約

- **戦闘**: 威力 = 力or魔力 + 武器威力 ± 相性、ダメージ = 威力 − 守備or魔防 − 地形。速さ差4以上で追撃。必殺は3倍。
- **相性**: 剣 > 斧 > 槍 > 剣（命中±15、威力±1）。
- **成長**: 経験値100でレベルアップ。能力ごとに成長率で上昇判定。
- **階位と流派（クラスチェンジ条件）**: 魔術は初級〜神級の階位、剣は剣神流・水神流・北神流の認可。Lv10以上＋階位で上級職へ。
- **無詠唱**: ルーデウスとシルフィエットの固有スキル。魔術での追撃判定に速さ+2。
- **支援**: 隣接して戦闘すると絆ポイント。ランクに応じて隣接時に命中・回避・必殺の補正。
- **拠点**: 難民キャンプ。章が進むごとに建物と住人が増える（復興の進み具合が見える）。
- **難易度**: カジュアル（倒れても次章で復帰）／クラシック（復帰しない）。
