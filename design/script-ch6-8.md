# 脚本 — 第6章〜第8章

『フィットア奪還戦記』第6章・第7章・第8章の脚本（本作書き下ろし）。筋は design/plot.md §2 の各章の「場面の一覧」に従う。

## 書式

- 書式は design/script-ch1-2.md の「書式」の節と同じ。場面の `###` 見出しに場面名と発生条件、台詞は1行1発言で `話者｜表情｜本文`。
- 見出しのすぐ下に `BGM：<曲名>`、その次に `背景：<背景名>` を1行ずつ書く。どちらも台詞の行の間に書けば、そこで切り替わる。戦闘中の会話は `背景：なし`（地図の上に重ねる）。
  - 曲名は design/asset-orders.md「1. 音楽」、背景名は同「2. 背景」のファイル名。`そのまま`＝直前の曲、`なし`＝無音。
  - この3章には一枚絵（`一枚絵：`）の行はない（plot.md §6.3 に第6〜8章の一枚絵がないため）。
- 表情は normal / smile / angry / sad。敵（オーベール、ドルガン、ヴェラ、バラク）は normal / angry のみ。アリエルのデレ顔（dere）は第9章が初出なので、この3章では使わない。
- ルーデウスの台詞で全体が（　）に入っているものは心の中の声（一人称「俺」）。声に出す台詞は丁寧語で一人称「僕」。
- 話者名と立ち絵IDの対応（script-ch1-2.md にないもの）：
  - 仲間：ロキシー→roxy、エリナリーゼ→elinalise、シルフィエット→sylphiette、アリエル→ariel、ザノバ→zanoba、クリフ→cliff、リニア→linia、プルセナ→pursena、イゾルテ→isolde（いずれも CHARS／CAST の名前で引ける）。
  - 会話のみ：ナナホシ→nanahoshi（SPEAKER_IDS に既存）。
  - 敵：オーベール→auber（既存）、ヴェラ→mercboss（**SPEAKER_IDS に「ヴェラ」を足す**。既存の「傭兵団長」と同じ絵）、バラク→barak（**SPEAKER_IDS に足す**。立ち絵は plot.md §6.2 で発注）。
  - 使徒：`使徒｜-｜…`（立ち絵なし。plot.md §1.4・§7 のとおり、素顔が分かる第10章終幕まで絵を出さない）。
  - 立ち絵なしの話者：ハンナ、トト、ベルト（第1〜2章の脇役）、傭兵の使者、検地官、密猟者、獣族の子。
- ナナホシとルーデウスが日本語で話す場面は、地の文で「ここからの言葉は、日本語だった」と示すだけで、表記は変えない。

## 実装担当への注記

### 必要な仕組み（plot.md §5 にあるもの以外、または注意が要るもの）

1. **背景の行**：見出しの下の `背景：` に加え、台詞の間の `背景：` で場面の途中に背景を切り替える（7章開幕、8章開幕・終幕）。plot.md §5 M10 の行ごとの `bg?` で足りる。
2. **話者名の追加**：SPEAKER_IDS に `'ヴェラ': 'mercboss'` と `'バラク': 'barak'` を足す。「使徒」は既存の `apostle` に結ばれているが、この3章では表情を `-` にしているので立ち絵は出ない（M12）。
3. **敵が話者の会話の飛ばし**：7章⑥（6ターン目・敵軍）は、バラクがそれまでに倒されていたら再生しない。6章⑤のオーベールの台詞は、増援が実際に出たときにだけ出る（`reinforce` にひも付け済み）。
4. **8章③の増援**：増援は結晶ごとに分かれる（M6）。会話は「3ターン目に結晶から最初に出た増援」にひも付ける。3つとも砕かれていれば会話は飛ぶが、筋に必要な情報はない。
5. **7章③の檻の道具**：檻（M13）が未実装で家屋の代用にする場合は、③の3行目（ルーデウスの「開ければ、役に立つものも」）を削る。
6. **離脱・未出撃の仲間の台詞**：どの戦闘中の会話も、強制出撃でない仲間の行が飛んでも話が通じるように書いた（6章②のエリナリーゼ、⑤のアリエルとシルフィエット、7章⑤のエリスとギレーヌ、8章②のエリス、③のロキシー、⑦のパウロ）。8章⑦はパウロがいなければルーデウスの心の声だけで完結する。開幕・終幕でも、クラシックで倒れた仲間の行は同じ規則で飛ばしてよい。
7. **6章の終幕**：12ターン耐えた場合も、敵の全滅で先に勝った場合も通じる（検地官は日暮れに着く）。ヴェラの撃破・ドルガンの撃破の有無にもよらない。

### 補足（plot.md から変えた点・判断したこと）

- 6章の「三日後に検地官が来る」は、開幕の途中で地の文の「三日目の朝」に飛ばし、戦闘を三日目（検地官が日暮れに着く日）にした。12ターンは「日暮れまで」と言い表した。
- 8章の終幕は、崩落と点呼の場面だけ `forest`（坑道の外）にし、キャンプに戻ってから plot.md どおり `camp_sunset` → `tent_inside` にした。
- 8章の終幕で、ナナホシの「転移事件と自分の来訪の関係」と「怖がられる知り合い」は、皆が出たあとの日本語の会話に入れた（ナナホシが異世界から来たことを仲間に明かさないため）。
- ナナホシの本名「七星静香」を6章の幕間で一度だけ名乗らせた。
- リニアの「〜ニャ」、プルセナの「〜なの」は要確認のため、1場面に1〜2回までに抑えた。
- 使徒の決め台詞案（plot.md §1.4「戻りたいと願うことの、何が悪いのです」）は第10章の担当のために残し、8章では使っていない。

### 新しく名前を付けた脇役

- なし。名前のない話者として「傭兵の使者」「検地官」（6章）、「密猟者」「獣族の子」（7章）がいる（すべて立ち絵なし）。ヴェラ、バラクは plot.md の名前のある敵。

### 後の章（第9〜10章）の担当へ引き継ぐ伏線

- **使徒＝ウォルド**：8章の開幕で使徒は「懐かしい。大きくなりましたね」と言い、ルーデウスは「古い紙の匂い」を感じる（ロアの書庫で本を貸していた記録官）。使徒は「空けていただきたいだけです。……あの日の、とおりに」と言う（住人がいると陣が乱れる、転移の日の再現が望み）。名前・素顔は出していない。
- **残滓の影が人の形**：8章③で「転移の光に呑まれた人の影」のように見える。第10章の「失われた人は戻らない」の下地。
- **輪の中心はブエナ村**：8章の終幕でナナホシが告げ、ルーデウスが「あの丘だ」と受ける。発動すれば今いる人々がもう一度飛ばされる、とも言っている。
- **オルステッド**：8章の終幕でナナホシが「とても強くて、とても怖がられる知り合い」と言う（名前は出していない）。第9章の幕間につなぐ。
- **貴族の証拠**：6章で雇い主ベイルマン伯爵の名、ドルガン（撃破時）が「上級大臣の屋敷に出入りする白い服の男」。7章でダリウスの印のある土地買い付けの書状、帳簿、バラクの「白い旦那」。アリエルは「王宮に訴えられる」と言った。第9章の王宮の命につなぐ。
- **オーベールの退場**：6章⑥で「この仕事からは手を引く」と言って去る。以後は出ない。
- **リーリャ・アイシャ・ノルン**：6章の幕間で、リーリャとアイシャはシーローンで無事、ノルンはゼニスの実家（ミリス）に預けてある、とパウロが言う（ノルンの所在は3章の幕間で既出の想定で、言い直しても通じる形にした）。二人を迎えに行く段取りは終章の担当に任せる。パウロの「あとは母さんだけだ」は、終章でパウロがゼニスの手がかりを追って旅立つことにつながる。
- **アリエルの段階**：6章終幕「駒ではなく……民なのね」、7章幕間「ええ。協力者」、8章幕間「今のは、聞かなかったことにして」。デレ顔は使っていない（第9章が初出）。8章幕間の「名前も顔も、全部覚えてる」は、顔を消した使徒との対比として使える。
- **主題**：7章でリニアの「戦略的撤退」をギレーヌが「逃げたと言う」と切り、8章⑦でルーデウスが「全員で帰る。それは、逃げじゃない」に行き着く。第10章のオルステッド戦（退かない）と対になる。
- **支援会話・後日談の種**：イゾルテ×エリスの「決着がついていない」、ハンナがプルセナに「今日からうちの子だ」、トトとリニアの値切り合い、クリフのエリナリーゼへの一目惚れ（扱いは未決のまま、笑いにとどめた）、ザノバの人形とロキシーの拒否、ギレーヌの字の練習。
